# Placeholder gt Table

Placeholder gt Table

## Usage

``` r
out_gtPlaceholder(..., id = NULL)
```

## Arguments

- ...:

  `character` Text to describe what is required, as a string, character
  vector, or multiple strings or character vectors.

- id:

  `character` An optional ID for the table.

## Value

A [`gt::gt()`](https://gt.rstudio.com/reference/gt.html) with a
placeholder.
