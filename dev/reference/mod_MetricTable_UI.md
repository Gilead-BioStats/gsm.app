# Metric Table Module UI

Metric Table Module UI

## Usage

``` r
mod_MetricTable_UI(id)
```

## Arguments

- id:

  `character` The id for this element.

## Value

A [`bslib::card()`](https://rstudio.github.io/bslib/reference/card.html)
with an optional title and a
[`gsm.kri::Report_MetricTable()`](https://gilead-biostats.github.io/gsm.kri/reference/Report_MetricTable.html).
