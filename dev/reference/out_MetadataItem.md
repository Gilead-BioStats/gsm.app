# Metadata list item

Metadata list item

## Usage

``` r
out_MetadataItem(strLabel, strValue)
```

## Arguments

- strLabel:

  `character` The label of a field.

- strValue:

  `character` The value of a field.

## Value

A
[`htmltools::div()`](https://rstudio.github.io/htmltools/reference/builder.html)
with the label, a spacer, and the value.
