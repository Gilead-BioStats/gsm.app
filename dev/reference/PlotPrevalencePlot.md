# Generate the prevalence ggplot

Generate the prevalence ggplot

## Usage

``` r
PlotPrevalencePlot(dfPrevalence, strCategory)
```

## Arguments

- dfPrevalence:

  `data.frame` The prepared data.

- strCategory:

  `character` A category to focus on.

## Value

A
[`ggplot2::ggplot()`](https://ggplot2.tidyverse.org/reference/ggplot.html).
