# Intelligently format numeric data

Intelligently format numeric data

## Usage

``` r
out_gtSmartFmtNumbers(gt_object, intMaxDecimals = 5L)
```

## Arguments

- gt_object:

  A [`gt::gt()`](https://gt.rstudio.com/reference/gt.html) object to use
  interactively.

## Value

A [`gt::gt()`](https://gt.rstudio.com/reference/gt.html) with numeric
formatting applied.
