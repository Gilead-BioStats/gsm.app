# Split a data frame by a grouping variable.

Split a data frame by a grouping variable.

## Usage

``` r
splitByGrouping(df, strGroupingVar, strValueVar)
```

## Arguments

- df:

  `data.frame` A data frame to wrangle.

- strGroupingVar:

  `character` The name of the grouping variable.

- strValueVar:

  `character` The name of the value variable.

## Value

A named list of values.
