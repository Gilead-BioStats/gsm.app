# Subset Choices

Subset Choices

## Usage

``` r
SubsetChoices(strDependent, l_chrChoices, envCall = rlang::caller_env())
```

## Arguments

- strDependent:

  `character` The value of the dependency. Can be `NULL`.

- l_chrChoices:

  `list` A named list of choice vectors.

## Value

`character` A vector of choices.
