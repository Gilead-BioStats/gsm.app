# Validate Selected Item

Validate Selected Item

## Usage

``` r
ValidateSelected(strCurrentSelection, chrChoices, strDefault = "All")
```

## Arguments

- strCurrentSelection:

  `character` The current selection.

- chrChoices:

  `character` The available choices.

- strDefault:

  `character` The default value to return if the current selection is
  not in the available choices.

## Value

`character` The validated selection.
