# Study, Group, and Participant label buttons

Study, Group, and Participant label buttons

## Usage

``` r
mod_DynamicLabelKey_UI(id)
```

## Arguments

- id:

  `character` The id for this element.

## Value

A
[`htmltools::span()`](https://rstudio.github.io/htmltools/reference/builder.html)
element containing a set of
[`shinyWidgets::checkboxGroupButtons()`](https://dreamrs.github.io/shinyWidgets/reference/checkboxGroupButtons.html).
