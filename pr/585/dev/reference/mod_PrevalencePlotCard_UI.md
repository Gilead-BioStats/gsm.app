# Interactive plots of prevalence of categorical variables

Interactive plots of prevalence of categorical variables

## Usage

``` r
mod_PrevalencePlotCard_UI(id, strPlotTitle = NULL)
```

## Arguments

- id:

  `character` The id for this element.

- strPlotTitle:

  `character` A title for a plot, usually the name of a metric.

## Value

A [`bslib::card()`](https://rstudio.github.io/bslib/reference/card.html)
with an interactive prevalence plot.
