# Reload app from reset button

Reload app from reset button

## Usage

``` r
srvr_Reset(input, session)
```

## Arguments

- session:

  `environment` Session from which to make a child scope (the default
  should almost always be used).

## Value

A [`shiny::observe()`](https://rdrr.io/pkg/shiny/man/observe.html) to
apply the reset.
