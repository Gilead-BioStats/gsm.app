# Plugins Wrapper UI

Plugins Wrapper UI

## Usage

``` r
mod_Plugins_UI(id, lPlugins = NULL)
```

## Arguments

- id:

  `character` The id for this element.

- lPlugins:

  `list` Optional list of plugins to include in the app.

## Value

Plugins UI elements, either as a tab (if there is only one plugin) or in
a drop-down list (for multiple plugins).
