# Install Plugin Package Dependencies

Plugins can have additional dependencies that are invisible to the usual
CI/CD pipelines. Use this function to install any such dependencies
using the pak package.

## Usage

``` r
plugin_InstallDependencySources(lPlugin)
```

## Arguments

- lPlugin:

  `list` A named list with required elements `meta` and `shiny`, and
  optional fields `spec`, `packages` and `required_inputs`. Usually
  generated by
  [`plugin_Read()`](https://gilead-biostats.github.io/gsm.app/dev/reference/plugin_Read.md).

## Value

`lPlugin`, invisibly. This function is called for its side effects.
