# Load Plugin Dependencies

Load the package dependencies of a plugin. This is designed to be used
in an `app.R` file to ensure that the dependencies are detected by
packages like rsconnect.

## Usage

``` r
plugin_LoadDependencies(lPlugin)
```

## Arguments

- lPlugin:

  `list` A named list with required elements `meta` and `shiny`, and
  optional fields `spec`, `packages` and `required_inputs`. Usually
  generated by
  [`plugin_Read()`](https://gilead-biostats.github.io/gsm.app/dev/reference/plugin_Read.md).

## Value

`lPlugin`, invisibly. This function is called for its side effects.

## Examples

``` r
if (FALSE) { # interactive()
plugin_LoadDependencies(list(packages = list(list(name = "gsm.app"))))
}
```
