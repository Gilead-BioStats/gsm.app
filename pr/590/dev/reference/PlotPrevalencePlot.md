# Generate the prevalence chart

Generate the prevalence chart

## Usage

``` r
PlotPrevalencePlot(dfPrevalence, strCategory)
```

## Arguments

- dfPrevalence:

  `data.frame` The prepared data.

- strCategory:

  `character` A category to focus on.

## Value

A
[`gsm.vizr::bars()`](https://gilead-public.github.io/gsm.vizr/reference/bars.html)
htmlwidget.
